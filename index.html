About Me

I am a Computer Science undergraduate majoring in Multimedia Computing with Honours at Universiti Malaysia Sarawak (UNIMAS). My approach pairs fundamental software engineering disciplines—such as memory management, object-oriented design, and normalized database schemas—with creative multimedia workflows, shader logic, and interactive user interfaces.

Whether building 2D graphics simulation engines from scratch or prototyping accessible transit workflows, I focus on clean code structure, predictable state management, and intuitive user experiences.
